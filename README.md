# LOST ISLAND — 3D Multiplayer prototype

ต้นแบบเกม 3D มุมกล้องบุคคลที่ 3 เล่นออนไลน์ 8 คนต่อห้อง (ห้องชั่วคราวในหน่วยความจำ)

## เปิดในคอม
1. ติดตั้ง Node.js 20+ และเปิด Terminal ในโฟลเดอร์นี้
2. `npm install`
3. `npm run dev`
4. เปิด `http://localhost:5173` (เปิดสองแท็บเพื่อทดสอบออนไลน์)

## ควบคุม
- WASD เดิน, Shift วิ่ง, Space กระโดด, E เก็บทรัพยากร
- ลากเมาส์เพื่อหมุนกล้อง
- มือถือ: จอยซ้าย, ปุ่มกระโดดและเก็บด้านขวา
- แชร์รหัสห้องเดียวกันเพื่อเจอกัน (สูงสุด 8 คน)

## Deploy บน Render
1. สร้าง GitHub repository แล้วอัปโหลดไฟล์ทั้งหมด (ยกเว้น node_modules/dist)
2. Render > New > Blueprint เลือก repo ที่มี `render.yaml` หรือ New > Web Service
3. Build command: `npm install && npm run build`
4. Start command: `npm start` และ Runtime: Node
5. เปิด URL ของ Render แล้วให้เพื่อนเปิด URL เดียวกันและใส่รหัสห้องเดียวกัน

**ข้อจำกัดต้นแบบ:** ห้องและทรัพยากรรีเซ็ตเมื่อเซิร์ฟเวอร์รีสตาร์ต, ความหิว/กระหายเป็นสถานะฝั่งเครื่อง, ไม่มีบัญชี/ฐานข้อมูล/คราฟต์/สร้างบ้าน, เซิร์ฟเวอร์ยังไม่ได้ทำ authoritative movement/anti-cheat สมบูรณ์ และบน Render Free อาจมี cold start และการเชื่อมต่อหลุดเมื่อบริการพัก. ควรปรับปรุงก่อนเปิดให้คนทั่วไปเล่นจำนวนมาก.
